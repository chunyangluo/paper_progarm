# 模型训练报告

## 1. 训练概述

本次训练使用收集得到的中文钓鱼文本数据集进行模型训练，主要测试了BERT-TextCNN混合模型的性能。训练过程采用了混合精度训练和梯度累积技术，以优化训练效率和模型性能。

## 2. 数据集信息

- **主要训练数据集**：`dataset_20260411_chifraud.csv`
- **数据来源**：CHIFRAUD中文钓鱼文本数据集
- **数据集规模**：包含8280个样本
- **数据分布**：正样本（钓鱼）和负样本（正常）分布均衡

## 3. 模型配置


| 配置项      | 值                           |
| -------- | --------------------------- |
| 模型架构     | BERT-base-chinese + TextCNN |
| 批大小      | 16                          |
| 学习率      | 1e-5                        |
| 训练轮数     | 15                          |
| 早停机制     | 启用（patience=2）              |
| 正则化      | L2正则化 + Dropout(0.6)        |
| BERT冻结策略 | 底层8层冻结，只微调顶层4层              |
| 优化技术     | 混合精度训练 + 梯度累积               |

## 5. 模型性能分析

### 5.1 优势

1. **高精度**：模型在测试集上达到了99.34%的准确率，表明模型能够准确区分钓鱼文本和正常文本
2. **高召回率**：99.42%的召回率确保了大多数钓鱼文本都能被检测出来
3. **优秀的F1分数**：0.9934的F1分数表明模型在精确率和召回率之间取得了良好的平衡
4. **出色的AUC分数**：0.9991的AUC分数表明模型具有很强的区分能力
5. **高效推理**：160样本/秒的推理速度确保了实时检测的可行性

### 5.2 挑战

1. **计算资源需求**：BERT模型参数量较大，训练过程需要一定的计算资源
2. **数据依赖性**：模型性能高度依赖于训练数据的质量和多样性
3. **泛化能力**：在处理高度迷惑性的钓鱼文本时，模型性能可能会下降

### 6.2 分析

- **TextCNN模型**：在小规模数据集上表现完美，但可能存在过拟合风险
- **BERT-TextCNN**：在大规模数据集上表现优异，具有更好的泛化能力
- **困难数据集**：当面对高度迷惑性的钓鱼文本时，模型性能会下降，但召回率仍然保持在较高水平

## 8. 结论与建议

### 8.1 结论

本次模型训练取得了优异的性能指标，BERT-TextCNN混合模型在中文钓鱼文本检测任务中表现出色。模型具有高精度、高召回率和良好的泛化能力，能够有效识别钓鱼文本。

### 8.2 建议

1. **数据增强**：可以通过数据增强技术进一步提高模型的泛化能力
2. **模型优化**：可以尝试不同的BERT变体（如RoBERTa、ALBERT）以提高性能
3. **多模态融合**：可以考虑融合文本和网络特征，进一步提高检测准确率
4. **持续更新**：定期更新训练数据，以适应不断变化的钓鱼文本模式
5. **部署优化**：可以考虑模型压缩技术，以减少模型大小和推理时间
