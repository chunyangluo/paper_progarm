# 网络特征采集指南

## 问题分析

原多模态模型存在致命问题：
- `_generate_network_features` 生成的是固定值（响应时间固定1.5、加载状态固定1等）
- `_generate_url_features` 只是基于URL字符串的简单规则特征
- 这些是**假特征**，没有真实业务数据支撑

## 解决方案

### 1. 采集真实网络特征

运行网络特征采集脚本：

```bash
python collect_network_features.py --dataset ../data/versions/dataset_20260411_chifraud.csv
```

**参数说明：**
- `--dataset`: 输入数据集路径（默认：`../data/versions/dataset_20260411_chifraud.csv`）
- `--output`: 输出数据集路径（可选，默认自动生成）
- `--batch_size`: 批量大小（默认：100）
- `--delay`: 请求延迟（默认：1.0秒）

### 2. 采集的8维网络特征

采集的网络特征（与 `network_feature_dim=8` 匹配）：

| 维度 | 特征名称 | 说明 |
|------|---------|------|
| 0 | 响应时间 | URL响应时间（秒，限制在10秒内）|
| 1 | 加载状态 | 1=成功，0=失败 |
| 2 | 重定向次数 | HTTP重定向次数 |
| 3 | 包含表单 | 1=包含，0=不包含 |
| 4 | 请求敏感信息 | 1=URL包含敏感关键词，0=不包含 |
| 5 | 使用HTTPS | 1=是，0=否 |
| 6 | 页面大小 | 页面内容大小（KB，限制在100KB内）|
| 7 | 敏感内容标记 | 1=页面包含敏感内容，0=不包含 |

### 3. 反爬规避措施

- **随机User-Agent**：从User-Agent池中随机选择
- **请求延迟**：可配置的延迟时间（默认1.0秒）+ 随机抖动
- **忽略SSL错误**：钓鱼URL常无有效证书
- **超时保护**：10秒超时，避免卡死

### 4. 性能优化

- **批量保存**：每采集100条保存一次，防止数据丢失
- **断点续采**：支持从已采集的位置继续
- **异常处理**：采集失败时返回默认值，不中断批量任务

## 使用流程

### 完整流程

```bash
# 1. 生成版本数据集（如果还没有）
python update_dataset.py

# 2. 采集网络特征
python collect_network_features.py

# 3. 训练多模态模型（使用真实特征）
python train_multimodal.py
```

### 网络特征文件说明

采集完成后会生成新文件：`dataset_20260411_chifraud_with_network_features.csv`

新文件包含：
- 原有所有列
- 新增 `network_features` 列：8维特征，逗号分隔的字符串

## 注意事项

1. **采集时间**：根据数据集大小，采集可能需要较长时间
   - 41398条样本 × 1.5秒/条 ≈ 17小时

2. **分批采集**：如果时间太长，可以分多次运行
   - 脚本支持断点续采

3. **网络稳定性**：确保网络连接稳定
   - 失败的URL会使用默认特征，不影响整体流程

4. **代理设置**：如需使用代理，可修改 `collect_network_features.py` 中的请求代码
