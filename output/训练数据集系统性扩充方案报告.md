## 四、数据清洗与预处理流程

### 4.1 清洗流水线

```
原始数据 → 空值过滤 → 长度过滤 → 跨数据集去重 → 内部去重 → 标签验证 → 列标准化 → 格式统一
```

| 步骤 | 处理逻辑 | 阈值 |
|------|---------|------|
| 空值过滤 | 删除text列为空的行 | - |
| 短文本过滤 | 删除text长度<2的行 | ≥2字符 |
| 长文本过滤 | 删除text长度>5000的行 | ≤5000字符 |
| 跨数据集去重 | 与已有数据集比较text字段 | 完全匹配 |
| 内部去重 | 基于text字段去重 | 完全匹配 |
| 标签验证 | 只保留label为0或1的行 | 0/1 |
| 列标准化 | 统一为12列格式 | EXISTING_COLUMNS |
| 格式统一 | text去除首尾空格，url/scenario填充默认值 | - |

| 处理步骤 | 数据量 | 移除量 |

| 文本去重后 | 163,310 | 12,088 |
| 标签验证后 | 163,310 | 0 |

## 六、数据质量监控机制

### 6.1 自动化质量检查脚本

质量检查已集成到扩充流水线中（`dataset_expansion_100k.py`的`_quality_check`方法），包含以下监控项：

```python
监控项清单:
1. null_text: text字段空值数（目标: 0）
2. null_label: label字段空值数（目标: 0）
3. duplicates: 重复文本数（目标: 0）
4. invalid_labels: 无效标签数（目标: 0）
5. short_texts: 过短文本数（目标: 0）

9. source_distribution: 数据来源分布
```

### 6.2 数据漂移检测

| 监控维度 | 检测方法 | 预警阈值 |
|---------|---------|---------|
| 标签分布漂移 | 正负比例偏离50:50 | 偏离>5% |
| 文本长度漂移 | 新数据均值与基准比较 | 偏离>20% |
| 场景分布漂移 | 场景占比与基准比较 | 偏离>10% |
