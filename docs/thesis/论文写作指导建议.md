# 论文写作指导建议

> 适用题目：**基于 BERT-TextCNN 混合模型的多模态网络钓鱼攻击智能识别系统**  
> 目标：帮助论文正文与当前代码、实验结果、系统实现保持一致，避免夸大实验结论，提升评审阅读体验。

## 1. 总体写作原则

### 1.1 论文主线

论文应围绕以下主线展开：

```text
中文网络钓鱼检测任务
  -> 多源信息处理需求
  -> BERT-TextCNN 核心识别模型
  -> 前后端智能识别系统实现
  -> 固定划分 + 三随机种子实验验证
  -> 多模态融合消融与局限分析
```

建议统一使用如下核心表述：

> 本文构建了面向中文网络钓鱼场景的多模态智能识别系统，系统能够处理文本、URL 与网络行为等多源信息，并将其用于输入解析、特征记录、预警辅助和可视化展示。核心识别模型采用增强版 BERT-TextCNN，通过融合 BERT 全局语义表示与 TextCNN 局部 n-gram 特征，实现对钓鱼文本的高精度识别。

### 1.2 术语统一

| 建议使用 | 不建议使用 | 原因 |
|----------|------------|------|
| 多源信息处理 | 多模态融合模型取得主要提升 | 当前部署模型不是多模态神经融合模型 |
| BERT-TextCNN 核心识别模型 | 多模态模型作为核心分类器 | 与代码和实验结果不一致 |
| URL 与网络行为用于辅助分析、记录、预警 | URL 与网络行为直接提升最终性能 | 消融实验未稳定支持该结论 |
| 漏报率降低具有安全意义 | 性能大幅超越 BERT | BERT 基线已接近天花板，提升幅度较小 |
| 工程化风险校准 / 规则兜底 | 纯神经网络端到端输出 | 系统存在规则兜底和安全后处理 |

### 1.3 结果表述尺度

论文中应强调“稳定、可复现、降低漏报率”，不要强调“大幅提升”。推荐写法：

> 实验结果表明，增强版 BERT-TextCNN 在固定划分和三随机种子设置下取得最高平均 F1，并相较强 BERT 基线进一步降低漏报率。由于 BERT 模型在该数据集上已接近性能天花板，本文模型的绝对提升幅度较小，但其在召回率和漏报率方向上的稳定改善具有网络钓鱼检测场景下的实际意义。

不建议写法：

> 多模态融合模型显著优于所有模型，是性能提升的主要来源。

## 4. 第一章 绪论

### 4.1 研究背景

写作重点：

- 网络钓鱼攻击通过短信、邮件、URL、伪造页面等形式传播；
- 中文场景中常出现“账户异常”“中奖”“积分过期”“身份验证”等诱导话术；
- 攻击文本短、变体多、伪装性强；
- 传统黑名单和人工规则难以及时覆盖新型样本。

可结合系统场景说明：

> 本文关注的钓鱼攻击不仅包含文本内容，还可能包含链接结构和页面行为线索，因此系统层面需要具备多源信息处理能力。

### 4.2 研究意义

建议从四个角度写：

1. 用户资产安全：降低用户点击恶意链接和泄露敏感信息风险；
2. 平台风控：辅助短信、邮件、社交平台进行内容安全审核；
3. 自动化检测：提升大规模样本处理效率；
4. 漏报风险控制：在安全任务中，漏报往往比误报更危险。

### 4.3 国内外研究现状

建议分四类综述：

- 传统机器学习：TF-IDF、逻辑回归、SVM、随机森林；
- 深度学习：TextCNN、LSTM、BiLSTM、注意力机制；
- 预训练语言模型：BERT、RoBERTa、ERNIE 等；
- 多模态/多源信息检测：文本、URL、HTML、网络行为、截图等。

多模态部分要写得谨慎：

> 多模态方法能够利用更多线索，但其效果高度依赖特征质量、覆盖率、融合策略和训练稳定性。本文实验也表明，直接引入手工 URL 与网络行为特征并不必然带来性能提升。

### 4.4 创新点

推荐写三个创新点：

1. 构建面向中文网络钓鱼任务的文本、URL、网络行为多源信息处理流程；
2. 设计增强版 BERT-TextCNN 混合模型，实现全局语义与局部 n-gram 特征互补；
3. 实现包含检测、预警、记录、模型管理、性能展示和功能演示的智能识别系统。

## 5. 第二章 相关理论与技术基础

### 5.1 网络钓鱼攻击

建议介绍：

- 钓鱼攻击定义；
- 常见载体：短信、邮件、URL、仿冒页面；
- 攻击流程：诱导文本 -> 恶意链接 -> 伪造页面 -> 信息窃取；
- 中文场景特点：短文本、强诱导、关键词变体。

### 5.2 文本表示方法

可按以下顺序写：

1. TF-IDF：简单、可解释，但难以建模上下文；
2. TextCNN：捕获局部 n-gram 模式，适合关键词和短语；
3. LSTM：建模序列依赖，但训练效率较低；
4. BERT：上下文语义表示强，但局部模式需要进一步利用。

### 5.3 BERT-TextCNN 原理

建议强调互补性：

- BERT 提供上下文相关的 token 表示；
- `[CLS]` 表示适合句级语义分类；
- TextCNN 可在 token 表示上提取局部可疑模式；
- 拼接后分类可综合全局语义和局部触发词。

### 5.4 系统开发技术

可简要说明：

- FastAPI：高性能 Python Web 框架，适合模型服务接口；
- Vue 3 + Element Plus：实现交互式检测系统；
- SQLAlchemy：结构化保存检测记录和预警记录；
- PyTorch + Transformers：实现 BERT-TextCNN 模型训练和推理；
- ECharts：性能数据和趋势可视化。

## 7. 第四章 BERT-TextCNN 模型设计

### 7.1 章节逻辑

建议按以下顺序写：

1. 模型设计目标；
2. 总体结构；
3. BERT 全局语义分支；
4. TextCNN 局部特征分支；
5. 特征融合与分类；
6. 训练策略；
7. 与旧版结构差异；
8. 多模态消融定位。

### 7.2 模型设计目标

推荐表述：

> 模型设计目标是在强 BERT 语义表示基础上进一步引入局部模式捕获能力，使模型既能理解上下文语义，又能识别钓鱼文本中常见的局部诱导短语和关键词组合。

### 7.3 模型结构描述

可以写成：

```text
Input text
  -> BERT encoder
  -> [CLS] global branch
  -> token sequence CNN branch
  -> projection and concatenation
  -> dropout
  -> fully connected classifier
  -> phishing / normal
```

### 7.4 训练策略

建议包含：

- 固定随机种子；
- balanced 训练配置；
- 交叉熵损失；
- AdamW 或对应优化器；
- 早停；
- 权重衰减；
- checkpoint 续跑；
- 多 seed 重复实验。

### 7.5 与旧模型关系

需要解释：

> 项目中保留 `BERTTextCNNLegacy` 是为了兼容早期部署权重。论文主模型应以增强版 `[CLS] + CNN` 融合结构为准，正式实验结果来自 `formal_20260501_rescued_hybrid`。

### 9.2 结果表格

建议使用如下主表：

| 模型 | Accuracy | Precision | Recall | F1 | FPR | FNR | AUC |
|------|---------:|----------:|-------:|---:|----:|----:|----:|
| TF-IDF + LR | 0.9181 | 0.9709 | 0.8620 | 0.9132 | 0.0258 | 0.1380 | 0.9592 |

### 9.3 主结果分析

建议分三段写：

1. 与传统机器学习相比：深度模型显著提升语义理解能力；
2. 与 TextCNN、LSTM 相比：BERT 类模型更强；
3. 与 BERT 相比：BERT-TextCNN 提升较小但降低漏报率。

### 9.4 FNR 单独分析

必须强调：

> 在网络钓鱼检测任务中，漏报样本意味着攻击未被系统拦截，其风险通常高于普通分类错误。因此，虽然 BERT-TextCNN 相较 BERT 的绝对提升幅度较小，但 FNR 的降低具有实际安全意义。

### 9.5 多模态消融分析

建议写为局限：

> 多模态融合实验未能稳定提升模型性能，说明在当前数据条件下，URL 与网络行为特征仍存在质量、覆盖率和分布稳定性不足的问题。该结果并不否定多源信息在系统层面的价值，而是说明深度融合需要更高质量的数据和更稳健的融合策略。

## 13. 常见评审问题与回答建议

### Q1：题目说“多模态”，为什么核心模型不是多模态融合模型？

建议回答：

> 本文中的“多模态”主要体现在系统层面对文本、URL 和网络行为等多源信息的处理、记录、预警和展示。实验中也进行了多模态融合消融，但结果显示当前特征质量和融合稳定性不足，未能稳定优于 BERT-TextCNN。因此，系统最终选择性能更稳定、可复现性更强的 BERT-TextCNN 作为核心识别模型。

### Q2：BERT-TextCNN 相比 BERT 提升很小，创新性如何体现？

建议回答：

> BERT 在当前数据集上已经接近性能天花板，因此绝对提升较小是合理的。本文创新点不只在单一指标提升，还包括模型结构上将全局语义和局部 n-gram 模式结合，并在三随机种子实验中实现更低漏报率。对于钓鱼检测任务，漏报率降低具有实际安全价值。

### Q3：多模态融合效果不好，会不会影响论文？

建议回答：

> 不会。多模态融合实验作为消融和局限分析，说明多源特征质量与融合策略对最终性能有重要影响。本文最终主线是多源信息处理系统和 BERT-TextCNN 核心识别模型，系统仍然支持多源信息输入、记录、预警和展示，实验结论与部署方案保持一致。
